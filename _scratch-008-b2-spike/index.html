Feature 008 — B2 capture spike

Disposable harness for the windowing GATE (T004–T006). Records the SAME ~60 s two ways so the multi-clip fidelity gate can compare them. Nothing here ships.

idle.

What to do

  1. Open this file over http://localhost or https:// (camera needs a secure context). On iPhone use real Safari.
  2. Enable the camera, keep your face framed and steady for the whole run.
  3. Click Record N stop/restart clips — it stops & restarts a single recorder each clip, downloading clip_00.*…clip_05.* (each a standalone, independently-decodable file).
  4. Click Record one continuous clip — one ~60 s recording, downloaded as continuous.*.
  5. Drop the files into packages/ml-video/tests/fixtures/multiclip/<chrome|safari>/ (clips into clips/), then run the gate (see smoke-tests.md).
